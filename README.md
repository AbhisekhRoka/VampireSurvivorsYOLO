# VampireSurvivorsYOLO
YOLO for the game Vampire Survivors
Object detection model to identify real-time game entities, including enemies, gems, and obstacles, from live screen capture.
Real-time decision-making pipeline utilizing OpenCV for image preprocessing and PyAutoGUI to simulate fluid keyboard mouse inputs.
Optimized frame processing latency to ensure rapid, sub-millisecond inference (12 frames per second) and high evasion accuracy during dense gameplay sequences using triangulation.
